# dados/

Pasta de entrada pra arquivos que o time cola aqui pra análise: planilhas, PDFs, prints de tela, exports de sistema.

- CSVs, XLSX, PDFs e imagens dropados aqui ficam fora do git por padrão (ver `.gitignore`) — podem ser sensíveis ou pesados.
- Skills como `relatorio-status` e `documentar-processo` leem arquivos desta pasta quando apontado pelo usuário.
- Não é uma pasta de armazenamento permanente — é zona de trânsito pra análise pontual.
